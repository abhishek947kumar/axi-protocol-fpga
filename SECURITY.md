# Security Policy

## Reporting Security Issues

This repository implements hardware IP and verification models for FPGA SoC communication. If you discover potential security vulnerabilities (e.g., unauthorized address space escape in crossbar decoders, bus hang exploits, or memory isolation bypass in protection bits `AxPROT`):

1. Please do not open public issues on GitHub.
2. Privately report the issue by contacting the repository maintainer.
3. Include detailed reproduction steps or testbench stimulus demonstrating the vulnerability.

We appreciate responsible disclosure to maintain high reliability and security standards for hardware designs.
